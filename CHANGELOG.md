# Changelog

## 0.1.0 — 2026-10-26

- First standalone DSH bundle release.
- Adds three defensive security workflows and a provider that registers them with the Harness skill registry.
- Adds dependency-free finding and coverage validators, Markdown report rendering, unit tests, and a deterministic ZIP packager.
- Targets DSH `0.2.1-rc.2`; runtime installation and live profile startup still require an external smoke test.
